# Viral Agency — Сайт-визитка

Лёгкий статический сайт (чистый HTML + CSS + JS) без сборщиков и лишних зависимостей.

## Как открыть локально
Просто открой `index.html` двойным кликом в любом браузере.

## Как добавить примеры роликов позже
1. Создай папку `videos/` рядом с `index.html` и положи туда 2–3 вертикальных ролика (`clip-1.mp4`, `clip-2.mp4`, `clip-3.mp4`).
2. В файле `index.html` найди комментарий `РЕЗЕРВНЫЙ БЛОК: ПРИМЕРЫ РОЛИКОВ (9:16)` и раскомментируй секцию `<section id="examples">...</section>`.

## Как выложить в интернет
Можно загрузить папку `viral-agency-site` целиком на **Cloudflare Pages**, **Vercel**, **Netlify** или **GitHub Pages** — всё заработает сразу без настройки сборки.
